OBJECTIF UTILISATEUR :
  L'utilisateur clique sur "Remplissage IA ✨" dans le popup.
  L'extension :
    1. Extrait le texte de l'offre d'emploi depuis la page courante
    2. Appelle le backend CVGen pour générer un CV + une LM personnalisés

    4. Uploade le CV généré dans le bon champ <input type="file">
    5. Uploade la LM générée dans le bon champ <input type="file">
    6. Affiche un résumé dans le popup : X champs remplis, CV uploadé ✓, LM ✓

1. content/offer-extractor.js
─────────────────────────────
But : extraire le texte de l'offre depuis la page courante.
- Cherche dans : <h1>, <h2>, balises avec class/id contenant
  "job", "offer", "poste", "description", "jobDescription"
- Cherche le nom de l'entreprise : balises avec "company", "employer", "entreprise"
- Cherche le titre du poste : <title>, premier <h1>
- Retourne : { title, company, offerText }
- offerText = concaténation de tout le texte pertinent trouvé (max 3000 caractères)
- Exposer via : window.OfferExtractor = { extract }

2. content/date-handler.js
──────────────────────────
But : remplir tous les types de champs date.
- <input type="date"> → valeur au format YYYY-MM-DD
- <input type="text"> avec placeholder "JJ/MM/AAAA" → format DD/MM/YYYY
- <input type="text"> avec placeholder "MM/AAAA" ou "MM/YYYY" → format MM/YYYY
- <input type="text"> avec placeholder "YYYY" → juste l'année
- Datepicker custom (class contient "datepicker", "date-picker", "react-datepicker",
  "flatpickr", "pikaday") :
    → focus() sur l'input
    → simuler la saisie caractère par caractère avec new KeyboardEvent('keydown')
    → déclencher 'input' + 'change' + 'blur'
- Deux selects séparés mois/année :
    → détecter par proximité dans le DOM (même parent ou label commun)
    → remplir chaque select séparément
- Exposer via : window.DateHandler = { fill(element, isoDateString) }
  isoDateString est toujours au format ISO : "2020-06" ou "2020-06-15" ou "2020"

3. content/file-uploader.js
────────────────────────────
But : uploader programmatiquement un PDF dans un <input type="file">.
- Fonction principale : FileUploader.upload(inputElement, base64String, filename)
  1. Décoder le base64 → ArrayBuffer → Blob → File
  2. Créer un DataTransfer, y ajouter le File
  3. Assigner inputElement.files = dataTransfer.files
  4. Déclencher les événements : 'input', 'change' (avec bubbles:true)
- Fonction de détection : FileUploader.findCVInput() et FileUploader.findCoverLetterInput()
  → Parcourir tous les <input type="file"> de la page
  → CV : label ou accept contient "cv", "resume", "curriculum"
  → LM : label ou accept contient "lettre", "cover", "motivation", "letter"
  → Si plusieurs inputs sans label clair : retourner le premier pour CV, le second pour LM
- Exposer via : window.FileUploader = { upload, findCVInput, findCoverLetterInput }

6. content/content-script.js (modifier)
─────────────────────────────────────────
Ajouter le handler SMART_FILL dans le switch de chrome.runtime.onMessage :

  case 'SMART_FILL':
    handleSmartFill()
      .then(result => sendResponse(result))
      .catch(err => sendResponse({ success: false, error: err.message }));
    return true;

Implémenter handleSmartFill() :
  async function handleSmartFill() {
    // 1. Extraire l'offre
    const offer = OfferExtractor.extract();

    // 2. Appeler le service worker
    const swResult = await sendToSW({ type: 'SMART_FILL', offerText: offer.offerText });
    if (!swResult.success) throw new Error(swResult.error);

    // 3. Remplir les champs texte/select/date avec les données du profil
    const fillResult = await handleFillForm({ overwrite: true, profil: swResult.profil });

    // 4. Uploader le CV
    let cvUploaded = false;
    if (swResult.cvBase64) {
      const cvInput = FileUploader.findCVInput();
      if (cvInput) {
        FileUploader.upload(cvInput, swResult.cvBase64, 'CV_CVGen.pdf');
        cvUploaded = true;
      }
    }

    // 5. Uploader la LM
    let lmUploaded = false;
    if (swResult.coverLetterBase64) {
      const lmInput = FileUploader.findCoverLetterInput();
      if (lmInput) {
        FileUploader.upload(lmInput, swResult.coverLetterBase64, 'LettreMotivation_CVGen.pdf');
        lmUploaded = true;
      }
    }

    return {
      success: true,
      filled: fillResult.filled,
      total: fillResult.total,
      cvUploaded,
      lmUploaded,
      offerTitle: offer.title,
      offerCompany: offer.company
    };
  }

8. popup/popup.js (modifier)

Ajouter le handler du bouton btn-smart-fill :

document.getElementById('btn-smart-fill').addEventListener('click', async function() {
  // Cacher le résultat précédent
  document.getElementById('smart-result').style.display = 'none';
  document.getElementById('smart-progress').style.display = 'block';

  const steps = [
    { label: 'Analyse de l\'offre…',     pct: 10 },
    { label: 'Génération du CV…',         pct: 35 },
    { label: 'Génération de la LM…',      pct: 60 },
    { label: 'Remplissage du formulaire…',pct: 80 },
    { label: 'Upload des documents…',     pct: 95 },
  ];

  // Simuler la progression visuelle pendant que le process tourne
  let stepIdx = 0;
  const interval = setInterval(() => {
    if (stepIdx < steps.length) {
      document.getElementById('progress-label').textContent = steps[stepIdx].label;
      document.getElementById('progress-fill').style.width = steps[stepIdx].pct + '%';
      stepIdx++;
    }
  }, 1200);

  try {
    const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });
    const result = await chrome.tabs.sendMessage(tab.id, { type: 'SMART_FILL' });

    clearInterval(interval);
    document.getElementById('progress-fill').style.width = '100%';
    document.getElementById('progress-label').textContent = 'Terminé !';

    setTimeout(() => {
      document.getElementById('smart-progress').style.display = 'none';
      document.getElementById('smart-result').style.display = 'block';

      let msg = result.filled + ' champs remplis';
      if (result.cvUploaded) msg += ' · CV uploadé ✓';
      if (result.lmUploaded) msg += ' · LM uploadée ✓';
      if (result.offerTitle) msg += '\n' + result.offerTitle;
      if (!result.cvUploaded) msg += '\n⚠ Aucun champ CV trouvé sur cette page';
      if (!result.lmUploaded) msg += '\n⚠ Aucun champ LM trouvé sur cette page';

      document.getElementById('result-text').textContent = msg;
    }, 600);

  } catch (err) {
    clearInterval(interval);
    document.getElementById('smart-progress').style.display = 'none';
    document.getElementById('smart-result').style.display = 'block';
    document.getElementById('result-text').textContent = '❌ Erreur : ' + err.message;
  }
});

CONTRAINTES TECHNIQUES
────────────────────────────────────────────────────────

- JavaScript vanilla uniquement (pas de bundler, pas de npm, pas d'import/export ES6)
- Exposer chaque module via window.NomModule = { ... }
- Aucun accès au DOM depuis service-worker.js (utiliser chrome.tabs.sendMessage)
- Compatible Manifest V3 (pas de background.page, pas de XMLHttpRequest dans SW)
- Pour le shadow DOM (Workday) : traverser récursivement element.shadowRoot
  dans offer-extractor.js et file-uploader.js
- Les événements synthétiques doivent utiliser { bubbles: true, cancelable: true }
  pour être captés par React, Angular et Vue
