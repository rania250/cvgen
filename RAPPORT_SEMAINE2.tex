\section{Conclusion}

C\^ot\'e extension Chrome, la base MV3 est fonctionnelle : popup connect\'e au compte CVGen, JWT stock\'e dans \texttt{chrome.storage.local}, d\'etection de 12 types de champs via \texttt{field-detector.js}, et remplissage valid\'e sur Indeed FR. L'architecture content script / service worker tient la route.

C\^ot\'e backend, les quatre entit\'es JPA sont en place (\texttt{UserProfile}, \texttt{Experience}, \texttt{Education}, \texttt{Skill}), les migrations V3 \`a V5 sont pass\'ees et les endpoints CRUD r\'epondent correctement. Le dashboard React r\'ecup\`ere bien les donn\'ees via Axios.

Le point critique pour la semaine 3 reste l'import CV (PDF/Word) --- c'est le pr\'erequis direct pour la g\'en\'eration automatique. Les deux sujets avancent en parall\`ele sans bloquer.
